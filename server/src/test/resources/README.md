# Recursos de teste

- `crypto-keys-test.json`: key ring **exclusivo de testes automatizados**. Não use estas chaves em
  nenhum ambiente real, backup ou instância local. Elas existem apenas para permitir que o contexto
  Spring suba com criptografia habilitada durante os testes.
- Fixtures de provedores (Pluggy) serão adicionadas em `fixtures/` nas histórias correspondentes.
